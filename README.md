# PHRAM-Qinghai-Tibet-R-code
High-altitude provinces exceed national pollution burden despite low ambient PM2.5. Household solid fuel PAF rises with elevation (r=0.745); PM2.5 PAF falls (r=−0.404). Elevation remains an independent predictor after confounder control (beta=0.438). Covariate-adjusted chain mediation quantifies the mechanistic pathway. 
The reproducible R code for this study is publicly available at https://github.com/zhanting-yang/PHRAM-Qinghai-Tibet-R-code/releases/tag/v1.0. All analyses were performed using R (≥4.2.0).
